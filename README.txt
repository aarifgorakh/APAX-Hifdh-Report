APAX Hifdh Report Generator – Web App Package

This package is ready to publish as a Progressive Web App (PWA).

Files:
- index.html: the web app
- manifest.json: installable app settings
- sw.js: offline service worker
- icon.png: app icon

To get a live web-app link, upload these files to a free static host such as:
1. GitHub Pages
2. Cloudflare Pages
3. Netlify

After publishing, open the HTTPS link on Android Chrome and choose:
Chrome menu (⋮) → Install app / Add to Home screen.

The app saves reports locally in the browser on the device unless a cloud database is added.
